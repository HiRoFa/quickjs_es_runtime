Struct CompositeHook 

Source 
pub struct CompositeHook<A, B> {
    pub first: A,
    pub second: B,
}
Expand description

A composable hook that combines two hooks.

Executes hooks in nested order:

  • Enter: first.enter -> second.enter
  • Exit: second.exit -> first.exit
